# Arcade Stick Case

A custom arcade stick case project with a double-compartment style layout.

The design in this repository is built around a **4-part case**:

1. Top part
2. Outer/main body
3. Bottom plate
4. Secondary compartment piece

Based on the existing project notes, the case also uses a **special screw/stop screw** so the bottom plate can be moved/repositioned while being kept in place.

## Repository contents

- `README.md` – project overview and preview
- `CAD Files` – the contents of the project aka CAD files
- `JOURNAL.md` – design/devlog notes and references

## Notes

- The model is based on a Korean-style lever layout.
- Compatibility with Japanese levers is currently unverified.
